# Aniq Haider — Portfolio

Personal portfolio built with Next.js 16, React 19, Tailwind CSS 4 and framer-motion.

## Develop

```bash
bun install
bun dev
```

## Deploy

Import the repo in Vercel (framework preset: Next.js). Optionally set `NEXT_PUBLIC_SITE_URL` to the production URL for canonical, sitemap and robots output.

Content lives in `src/lib/data.ts`.
